OVERLEAF UPLOAD
===============

1. Upload this entire folder, or upload overleaf_report.zip.
2. Set main.tex as the project's main document if Overleaf does not select it automatically.
3. Compile with pdfLaTeX.

All report figures are stored under figures/ and are referenced using relative paths.
No files outside this folder are required.

This revision uses evidence tables for architecture, hypotheses, protocol,
delay effects, interference, routing ablations, overwrite behavior, mechanistic
diagnostics, gate-free adaptive-kernel controls, assignment-defined stress metrics,
limitations, and the proposed follow-up experiment. It also includes the H7--H8
slow-memory experiments: fast/slow timescale separation, identity-default gating,
independent erase/write gates, the parameter-matched tied-gate control, long-delay
probes, drift, overwrite accuracy, and stale-value errors.
