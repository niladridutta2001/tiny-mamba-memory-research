\begin{abstract}\small
We investigate how a compact one-layer Mamba preserves, overwrites, and retrieves eight logical key--value registers. The trained baseline reaches 69.64\% over all queries in length-512 sequences, yet controlled balanced retrieval falls from 84.38\% at delay 10 to chance at delay 500. Unrelated-key SET events are more damaging than matched NOOP or QUERY controls. We therefore test key-conditioned write routing against a parameter-matched tied-row ablation. Their nearly identical accuracy and routing geometry falsify key selectivity as the source of the small observed gains. Mechanistic follow-ups instead identify accumulated passive transitions as the primary bottleneck: after the width-four convolution has washed out, forcing later NOOP recurrence to identity restores about 97\% accuracy through delay 128. Under altered decay, a separately trained long-horizon linear readout can recover information that the original short-trained classifier cannot, exposing a secondary readout-distribution mismatch. A gate-free adaptive-kernel study reaches the best aggregate stress accuracy but remains near chance on the 511-step final-gap probe and loses both controlled probes to its parameter-matched static mixture. The evidence supports co-designing retention and horizon-stable retrieval rather than adding local mixing or write-routing capacity alone.
\end{abstract}

For convolution-processed input \(u_t\), the readable selective scan is
\begin{align}
h_t &= \exp(\Delta_tA)\odot h_{t-1}+\Delta_tB_tu_t,\\
r_t &= C_th_t+D\odot u_t, \qquad A=-\exp(A_{\log})<0.
\end{align}
\begin{center}
\small\fbox{\parbox{0.92\linewidth}{\textbf{Mechanistic decomposition:} repeated \(\exp(\Delta_tA)\) controls retention; \(\Delta_tB_tu_t\) introduces new writes; \(C_th_t+D\odot u_t\) determines what is exposed to the downstream classifier.}}
\end{center}

\section{Part B: Key-Conditioned Write Routing}
The proposed model learns \(R\in\mathbb R^{8\times64}\). A SET to key \(k\) uses \(g_k=\sigma(R_k)\) to gate only the input-write term:
\begin{equation}
h_t=\exp(\Delta_tA)\odot h_{t-1}+g_k\odot(\Delta_tB_tu_t).
\end{equation}
This adds 512 parameters (10,661 total, +5.0\%). Non-SET writes are unchanged. The tied-row ablation keeps the same parameter table but averages rows during computation, eliminating key selectivity while retaining capacity. Both initialize to gate value 0.95.

\section{Supplementary Adaptive-Kernel Diagnostic}
The adaptive causal kernel uses one width-eight depthwise kernel and mixes nested causal masks for effective widths \(\{1,2,4,8\}\). The adaptive router predicts mixture weights from the current token-side representation; the parameter-matched static ablation learns one sequence-independent mixture. All models use the original Mamba recurrence with \emph{no event-conditioned retention gate} and were trained from scratch for 1,500 updates on lengths 32--128. Original Mamba is the fixed-width-four control; width eight changes only the fixed convolution. Because the router does not observe recurrent state directly, this experiment tests token-conditioned local context, not explicit overwrite detection.

\section{Reproducibility and Attribution}
All fixed splits, predictions, checkpoints, confidence intervals, and plots are stored under \texttt{results/}; detailed exploratory analyses are retained separately from this focused report. The principal commands are \texttt{train.py} with \texttt{configs/baseline.yaml}, \texttt{configs/proposed.yaml}, or \texttt{configs/ablation.yaml}, followed by \texttt{part\_b\_compare.py}. Tests run with \texttt{python -m pytest -q -p no:cacheprovider} (33 passed).

The readable Mamba code derives from John Ma's MIT-licensed \texttt{mamba-minimal}; equations follow Gu and Dao's Mamba formulation. The dataset generator and sample data were supplied with the assignment. AI assistance was used substantially for scaffolding, experiment scripts, plotting, and editing. I inspected the code paths, selected the hypotheses and controls, executed the experiments, verified artifacts, and take responsibility for the conclusions.
